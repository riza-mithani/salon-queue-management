# SALT N' PEPPER – Salon Queue Management System

A web-based salon queue management system built using Python and Streamlit.

## Overview

SALT N' PEPPER helps customers join a salon queue and track their waiting status. It also provides staff and salon owners with tools to manage queues, staff availability, services, and salon operations.

## Features

- Customer queue registration
- Live queue status tracking
- Reception dashboard for queue management
- Barber and stylist views
- Waiting area display
- Owner settings and service management
- Staff availability management
- Online queue control

## Technology Stack

- Python 3.12
- Streamlit
