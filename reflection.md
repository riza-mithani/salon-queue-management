\# Project Reflection



While developing the SALT N' PEPPER Salon Queue Management System, I used Antigravity to help me build the application using Python and Streamlit.



During development, I faced several issues. One issue occurred in the staff availability section. When I clicked the "Set Available" button for Stylist 2, the Home screen became blank. I noticed this while testing the application and asked Antigravity to check the button callback and session-state handling. After the correction, the button worked properly.



I also faced navigation issues where some buttons did not work as expected. The initial fixes did not completely solve the problem, so I provided more specific prompts about Streamlit navigation and session-state handling. I also needed to make several visual corrections to improve spacing, image positioning and card alignment.



Later, I added PIN protection to the Reception Dashboard, Barber View and Owner Settings. I used a shared demo PIN and tested access to all three staff screens while keeping the customer-facing screens public.



I also improved the application's mobile responsiveness so that all seven screens could fit different mobile screen sizes. Additionally, I updated the sidebar interaction to expand on mouse hover on desktop while retaining tap-based navigation on mobile devices.



This project helped me understand how to build a web application, test its features and fix errors. I learned that AI-generated code does not always work correctly on the first attempt. I had to check the application, identify problems and provide clearer follow-up prompts. This taught me the importance of testing and giving precise instructions when using AI tools.



Overall, I gained practical experience in Python, Streamlit, debugging, responsive design, application development and using AI tools to build a working project.
