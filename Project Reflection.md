# Project Reflection

While building the SALT N' PEPPER Salon Queue Management System, I used Antigravity to create the application and improve its features.

One issue I faced was in the staff availability section. When I clicked the "Set Available" button for a stylist, the Home screen became blank. I noticed this while manually testing the application.

I explained the problem to Antigravity and asked it to fix the callback and session-state handling without changing other parts of the application. After the changes, I tested the button again and the issue was fixed.

This project helped me understand how to build a web application using Python and Streamlit. I also learned that AI-generated code needs to be tested carefully. Giving clear prompts and checking each feature helped me improve the application step by step.

Overall, this project gave me practical experience in application development, debugging, testing, and using AI tools.
